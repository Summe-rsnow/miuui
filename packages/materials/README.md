# @xcmm1543/miuui-materials

μui `1.0.0` pluggable surface materials (`solidMaterial`, `micaMaterial`, `glassMaterial`, `materialPlugins`) with isolated `--miu-material-*` surface mappings inside `@layer miu-material` and `(prefers-reduced-transparency: reduce)` solid fallback. Import `@xcmm1543/miuui-materials/style.css` alongside `@xcmm1543/miuui-tokens/style.css`.

Part of the [μui](https://github.com/Summe-rsnow/miuui) monorepo.
