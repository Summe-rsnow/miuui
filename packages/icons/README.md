# @xcmm1543/miuui-icons

μui `1.0.0` named icon exports (75 C-style rounded UI, media, window, and navigation icons) bound to `--miu-icon-size-current` (`--miu-icon-size-*` tokens) and `currentColor`, with static (`@xcmm1543/miuui-icons`), dynamic (`@xcmm1543/miuui-icons/dynamic`), and brand (`@xcmm1543/miuui-icons/brand`) entrypoints.

Works seamlessly with `<Icon name="..." />` and component icon props typed as `IconProp` (`IconName | IconDefinition`), with single-icon tree-shaking (`PlusIcon` <= 2 KB gzip).

Part of the [μui](https://github.com/Summe-rsnow/miuui) monorepo.
