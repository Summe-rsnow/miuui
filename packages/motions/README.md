# @xcmm1543/miuui-motions

μui `0.7.0` pluggable motion tiers (`fullMotion`, `reducedMotion`, `noneMotion`, `motionPlugins`) inside `@layer miu-motion`, honoring `@media (prefers-reduced-motion: reduce)` across all component entrance and loop animations. Import `@xcmm1543/miuui-motions/style.css` to enable motion tier styles.

Part of the [μui](https://github.com/Summe-rsnow/miuui) monorepo.
