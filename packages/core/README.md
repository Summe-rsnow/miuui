# @xcmm1543/miuui-core

μui `0.7.0` framework-agnostic contracts (`ComponentSemanticProps`, `regionClass` / `regionStyle`, `resolveIconSize`), plugin interfaces (`MaterialPlugin`, `MotionTierPlugin`), built-in locale registries (`zh-CN`, `en-US` with `Intl` interpolation & plural fallback), and theme serialization — with zero Vue, Reka UI, or DOM dependencies.

Part of the [μui](https://github.com/Summe-rsnow/miuui) monorepo.
